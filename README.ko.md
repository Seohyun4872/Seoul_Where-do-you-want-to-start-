# 서울, 어디에서 창업할까?

### 외식업 소상공인을 위한 창업 인디케이터

[**창업 인디케이터 웹페이지 바로가기 →**](https://seohyun4872.github.io/Seoul_Where-do-you-want-to-start-/) · [English](README.md)

서울에서 외식업 창업을 준비하는 사람이 자신의 운영 조건에 맞는 상권을 탐색할 수 있도록 만든 지도 기반 웹페이지입니다. 데이터 분석의 최종 결과를 필터와 지도로 연결해, 분석 코드를 실행하지 않아도 후보 상권을 비교할 수 있게 했습니다.

## 프로젝트 배경

창업 입지를 고를 때는 매출 규모뿐 아니라 업종, 주로 영업할 시간대, 주중·주말 수요, 가격대, 집과의 거리도 함께 고려해야 합니다.

이 프로젝트는 이러한 조건을 직접 선택하고, 조건에 맞는 서울 상권을 지도에서 살펴볼 수 있는 창업 인디케이터를 만드는 데 목적이 있습니다.

## 팀 프로젝트 및 담당 역할

**DArt-B 2025년 2학기 학술제 팀 프로젝트**로 진행했습니다.

- **팀원:** 김미정, 김태연, 권남정, 노동희, 박서현, 신혜성
- **박서현 담당:** 데이터 전처리 및 웹페이지(창업 인디케이터) 구현

팀은 상권 데이터 분석과 지표 설계를 함께 진행했습니다. 저는 분석에 사용할 데이터를 전처리하고, 최종 분석 결과를 조건별로 탐색할 수 있는 웹 인디케이터로 구현했습니다.

| 최종 분석 대상 | 외식업종이 3개 이상 존재하는 1,026개 상권 |

## 데이터 분석 과정

| 단계 | 분석 방법과 목적 |
| --- | --- |
| 결측치 처리 | 항목 간 합계 관계를 검토해 0이 타당한 항목은 0으로 처리했습니다. 과거 동일 상권의 관측값을 활용하고, 남은 결측치는 랜덤포레스트 회귀로 보완했습니다. 지출 항목은 총금액과 세부 항목 비율을 추정해 정합성을 고려했습니다. |
| 이상치 검토 | 매출 합계와 시간대별 매출의 일치 여부, 점포 수와 영업 특성을 함께 검토했습니다. 큰 매출이나 0이라는 이유만으로 관측값을 일괄 제거하지 않았습니다. |
| 업종별 상권 분류 | 업종별 매출 비중에 Robust 스케일링과 PCA를 적용한 뒤 K-means로 10개 군집을 구성했습니다. Silhouette, Calinski–Harabasz, Davies–Bouldin 지표로 조합을 평가하고, 군집별 업종 특성을 바탕으로 업종과 군집을 연결했습니다. |
| 가격대 분류 | 업종별 가격대 분포에 따라 K-means, Gaussian Mixture Model(GMM), IQR 기반 방법 등을 비교해 저가·중가·프리미엄 유형을 정의했습니다. |
| 운영 시간대 | Friedman 검정으로 시간대별 매출 차이를 살펴보고, 분포 기반 임계값으로 점심·저녁·심야·균형형 등의 유형을 구분했습니다. |
| 운영 요일 | 요일별 매출 패턴을 검토해 분석 내 주말을 금·토, 주중을 일~목으로 정의했습니다. 일평균 매출의 MinMax 스케일링과 HDBSCAN 군집화, IQR 기준으로 주중·주말·균형형 및 강한 유형을 구분했습니다. |
| 인구 지표 | 유동·상주·직장 인구의 세부 변수를 검토하고 VIF로 다중공선성을 점검했습니다. 여러 모델에서 중요성이 확인된 변수를 업종별 설명에 활용했습니다. |
| 휴일 및 부가정보 | 요일별 매출 차이 검정과 군집별 분석을 바탕으로 휴무일 후보를 제시하고, 주요 집객시설·상권 변화 지표 등을 함께 제공했습니다. |

발표자료에서는 업종별 점포당 매출, 상권 내 매출 비중, 입지계수(LQ)를 결합한 **상권 대표 조정 매출액**을 설계했습니다. 현재 웹페이지의 순위는 저장된 `점포당_매출_num` 필드를 사용하고, 팝업의 예상 매출은 별도 데이터에서 조회합니다.

| 기능 | 내용 |
| --- | --- |
| 업종 선택 | 한식·양식·일식·중식·분식·치킨·커피·제과점·패스트푸드·호프/간이주점 |
| 운영 조건 필터 | 피크 시간대, 주중·주말 유형, 가격대에 따른 후보 탐색 |

| 업종별 설명 | 선택한 업종과 관련된 분석 설명 문장 표시 |

## 사용 방법

1. [웹페이지에 접속합니다.](https://seohyun4872.github.io/Seoul_Where-do-you-want-to-start-/)
2. 관심 있는 **업종**을 선택합니다. 처음에는 나머지 항목을 **선택없음**으로 두면 넓게 탐색할 수 있습니다.
3. 원하는 **피크시간대·주중/주말·가격대**를 설정합니다.
4. 거리도 고려하고 싶다면 **집 X에는 경도**, **집 Y에는 위도**를 입력하고 반경과 직주근접 여부를 선택합니다. 거리 조건이 필요 없다면 **상관없음**으로 둡니다.
5. **상권 추천** 버튼을 누릅니다. 왼쪽 Top 10 목록을 비교하고, 지도에서 강조된 상권이나 TOP 1~3 마커를 클릭해 상세 정보를 확인합니다.

추천 상권이 나오지 않으면 조건을 하나씩 완화해보세요.

## 추천 방식

업종별로 연결된 클러스터에서 후보를 찾고, 시간대·주중/주말·가격대와 선택한 거리 조건을 적용합니다. 남은 상권을 **점포당 매출 기준으로 정렬해 최대 10개**까지 보여줍니다.

팝업의 **예상 매출은 상권·업종별로 준비된 별도 값**이며, Top 10 순위를 정하는 기준과는 구분됩니다. 거리 조건은 집 좌표와 상권 중심점 사이의 직선거리를 사용하며, 도로 거리나 실제 통근시간을 뜻하지 않습니다.

## 분석 결과를 웹서비스로 연결

최종 분석 결과를 JSON·GeoJSON으로 준비하고, 사용자가 조건을 바꾸며 지도로 탐색할 수 있도록 구성했습니다. 이 저장소에는 웹 화면과 추천·시각화 로직, 웹에서 사용하는 분석 결과 데이터가 담겨 있습니다. 필터를 변경하면 저장된 결과를 조회하며, 모델을 새로 학습하지는 않습니다.
